Setup guide · Email/password + Google

Activate Google Sign-In

CodeItAll already supports email & password and a Continue with Google button on the Me / Account page. Follow this guide to turn Google on in Testing first, then move to Production.

Important: Auth APIs run on the droplet (/api/auth). Use http://188.166.214.47:8099/profile/ (or your HTTPS domain pointing at that API). Pure Vercel static hosting cannot finish Google login until /api/auth is proxied.

Part A — Testing mode

1. Create a Google Cloud project

  1. Open Google Cloud Console.
  2. Create/select a project (e.g. CodeItAll).

2. OAuth consent screen → Testing

  1. Go to APIs & Services → OAuth consent screen.
  2. User type: External.
  3. App name: CodeItAll. Add support/developer emails.
  4. Scopes: keep defaults for Sign-In.
  5. Test users: add every Gmail that should be able to log in while testing.
  6. Publishing status stays Testing.

Only listed test users can sign in during Testing.

3. Create Web OAuth Client ID

  1. Credentials → Create credentials → OAuth client ID.
  2. Type: Web application.
  3. Authorized JavaScript origins (no path):
http://188.166.214.47:8099
http://localhost:8099
http://127.0.0.1:8099
  1. Copy the Client ID (….apps.googleusercontent.com). Client Secret is not needed for this button flow.

4. Configure the server

sudo nano /etc/codeitall-assist.env
GOOGLE_CLIENT_ID=YOUR_CLIENT_ID.apps.googleusercontent.com
CIA_SITE_URL=http://188.166.214.47:8099
sudo /opt/codeitall-assist/venv/bin/pip install 'google-auth>=2.28.0'
sudo systemctl restart codeitall-assist
curl -s http://127.0.0.1:8100/auth/config

Expect "googleEnabled": true.

5. Deploy code + test

  1. Deploy updated auth_api.py, docs/profile/*, and docs/shared/progress.js.
  2. Open /profile/.
  3. Click Continue with Google with a test user account.
  4. Confirm email/password Sign in / Create account still works.

Part B — Production mode

  1. Put the site on HTTPS (e.g. https://codeitall.dev) pointing at the same API.
  2. In Google Cloud Credentials, add production origins: 
    https://codeitall.dev
https://www.codeitall.dev
  3. Set CIA_SITE_URL=https://codeitall.dev and restart assist.
  4. OAuth consent screen → Publish app (Testing → In production).
  5. Add a privacy policy URL on the consent screen if Google asks.
  6. Smoke test with a Gmail that is not on the old test-user list.

Checklist

Testing: consent=Testing · test users · JS origins · GOOGLE_CLIENT_ID · restart · button works

Production: HTTPS domain · prod origins · publish consent · non-test Gmail works · password login still works
